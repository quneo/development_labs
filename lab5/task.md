Задание на 5-ю лабу: реализовать многостраничное приложение с помощью dcc.Link, dcc.Location (а также возможно dbc.NavBar, dbc.NavLink). Основа для содержимого страниц - элементы 4-й лабы. На первой странице необходимо разместить выпадающий список для выбора станции, слайдер для выбора времени суток и график временного ряда с динамикой пассажиропотока по выбранной станции и времени. Тепловую карту и диаграмму рассеяния разместить на второй странице. Сохранить логику взаимодействия из 4-й лабы, т.е., например, при изменении списка станций все зависимые элементы должны обновиться. Используйте dcc.Store для кэширования данных. По возможности используйте clientside-callbacks. Дополнительно добавьте кнопки перехода между страницами. Добавьте 3-ю страницу с краткой информацией об авторе.
